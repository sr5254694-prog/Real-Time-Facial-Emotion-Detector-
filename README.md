# Real-Time Facial Emotion Detection

This project focuses on detecting human facial emotions in real time using computer vision and machine learning techniques. It demonstrates the practical application of AI in understanding human emotions through facial expressions.

## Overview
Facial emotion recognition plays an important role in human–computer interaction. This project captures live video input through a webcam and classifies facial expressions into different emotional categories.

## Technologies Used
- Python
- OpenCV
- Machine Learning
- Deep Learning (CNN)
- NumPy

## Key Features
- Real-time facial emotion detection
- Multiple emotion classification
- Live webcam-based processing
- Practical AI implementation

## Project Type
Academic and practical project developed as part of a BSc IT program.

## Future Scope
- Improve accuracy using advanced deep learning models
- Emotion analytics and reporting
- Integration with real-world applications
